# Characters built with the editor and checked against PCGen's own
# sheet for them (tests/it/reference.rs).
#
# == name            starts a scenario (also the character's name)
# gamemode MODE      game mode of the new character
# campaign KEY       a campaign to use (repeatable)
# anything else      an editor command, as typed in `pcgtools repl`

== fighter_35e
gamemode 35e
campaign 3.5 RSRD - Campaign Set - Core Books I - III
set stat STR 16
set stat DEX 13
set stat CON 14
race Dwarf
set align LN
class add Fighter
class add Fighter
feat add "Power Attack"
feat add Cleave
skill Climb 4
equip add "Chainmail"
equip wear "Chainmail"
equip add "Waraxe (Dwarven)"
equip wear "Waraxe (Dwarven)"
